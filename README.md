# grey-matter

A customized, adapted set of agent skills derived from a review of
[mattpocock/skills](https://github.com/mattpocock/skills), reshaped for my own
workflow and for game-centric (not just web-application) development.

## What lives here

- Per-skill review notes: what each skill is, what it does for the user, and how
  we want to customize it.
- A game-centric "lens" layer that reinterprets the web-focused skills for game
  development.
- Tickets tracked with [`tkt`](https://github.com/) in `.tickets/`.

## Status

Early. See `.tickets/` (run `tkt ready`) for the active work frontier.
