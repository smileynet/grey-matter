# Tracked tool-script inventory and usage map

This is an inventory and routing index, not permission to execute every entry. Read the named owning skill and reference before invoking an operator. Inventory discovery is read-only: this file lists tracked source paths and classifies their role; it never runs them.

**Scope:** this catalog describes the grey-matter source checkout. Commands naming
`scripts/` or `skills/` paths run from that identified checkout; run the coverage
checker from its source path there, not an installed copy with a different directory
layout. Installed copies of this reference provide routing for maintaining grey-matter,
not an inventory of another project's tools. For other projects, use their own guidance.

The active outcome's restrictions apply to every row, including distribution and release tools. This delivery cycle excludes Agy execution and global harness setting changes; ordinary task authorization does not silently lift a recorded security hold. Use the approved operation's scope and current project provider policy.

## Update procedure

Before adding, renaming or changing the role of a tracked script extension anywhere in the repository or an extensionless shebang executable:

1. Inspect the source/options without invoking it. Add its repository-relative path below with role `operator`, `module`, `test`, or `fixture/template`, and a reason.
2. For an operator, update the owning skill's `SKILL.md` to link its task-specific reference. The reference must cover when to use it, exact invocation/arguments and inputs, mutation and authorization, output/exit meaning, and verification/retention.
3. Run `node skills/engineering/orchestrate/scripts/check-tool-guidance.mjs` and its fixtures with `node --test skills/engineering/orchestrate/scripts/check-tool-guidance.test.mjs`.
4. Repeat the inventory after queued script-adding work lands (tickets 204, 205, 207, 179). Do not infer that a new path is covered by a broad family entry.

The checker is deliberately on-demand and read-only; it is not registered as a broad repository gate. It catches missing tracked paths, stale rows, invalid roles/reasons, dead anchors/paths and missing command/boundary/outcome fields in operator rows. These structural checks do not prove that guidance is semantically correct; source review still owns that judgment. Add fixture regressions when its contract changes.
