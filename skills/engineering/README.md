# engineering

Skills for building software: grilling an idea into a spec, slicing it into tickets,
implementing it test-first, reviewing it, and shipping it. The app/game split runs through
this bucket, where a skill differs by regime its game counterpart sits beside it.

The map over the whole set is [`compass`](../meta/compass/SKILL.md). This list is kept in
sync by [`curate-docs`](../meta/curate-docs/SKILL.md).

## User-invoked

- [grill-with-docs](./grill-with-docs/SKILL.md): sharpen an idea by interview, in a repo, leaving a `GLOSSARY.md`/ADR paper trail.
- [to-spec](./to-spec/SKILL.md): synthesise a grilled thread into a spec (no re-interview).
- [to-tickets](./to-tickets/SKILL.md): slice a spec into tracer-bullet tkt tickets with blocking edges.
- [implement](./implement/SKILL.md): build one ticket, driving tdd and code-review.
- [implement-spec](./implement-spec/SKILL.md): build a whole spec across the frontier on one integration branch.
- [triage](./triage/SKILL.md): move external requests + tkt tickets through triage roles.
- [wayfinder](./wayfinder/SKILL.md): chart a too-big effort as a map of decision tickets.
- [improve-codebase-architecture](./improve-codebase-architecture/SKILL.md): survey deepening opportunities as a visual report, then grill one.

## Model-invoked

- [grilling](../productivity/grilling/SKILL.md): the interview primitive (lives in productivity; listed here for reach).
- [tdd](./tdd/SKILL.md): the red-green agent feedback loop.
- [code-review](./code-review/SKILL.md): two-axis (Standards + Spec) review of a diff, files findings as tickets.
- [pr](./pr/SKILL.md): shape a PR body (smallest visual, evidence, merge-danger call).
- [diagnosing-bugs](./diagnosing-bugs/SKILL.md): a tight-feedback-loop method for the hard bugs.
- [prototype](./prototype/SKILL.md): throwaway code to answer one design question (logic / UI / game branch).
- [research](./research/SKILL.md): background agent investigates primary sources, leaves a cited file.
- [research-audit](./research-audit/SKILL.md): fresh-context validator that scores a research file.
- [retro](./retro/SKILL.md): improve the agent's environment after a session.
- [wizard](./wizard/SKILL.md): generate an interactive bash wizard for human-only setup steps.
- [domain-modeling](./domain-modeling/SKILL.md): sharpen an app's domain language (DDD), the app regime.
- [game-modeling](./game-modeling/SKILL.md): the game-native counterpart to domain-modeling.
- [codebase-design](./codebase-design/SKILL.md): deep-module vocabulary, the service regime.
- [game-native-design](./game-native-design/SKILL.md): the game-native philosophy, the frame-loop regime.
