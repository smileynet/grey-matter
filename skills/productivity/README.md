# productivity

Skills for thinking and communicating: interviewing to sharpen an idea, handing work off
between sessions, learning a topic, and repairing a message that didn't land.

The map over the whole set is [`compass`](../meta/compass/SKILL.md). This list is kept in
sync by [`curate-docs`](../meta/curate-docs/SKILL.md).

## User-invoked

- [grill-me](./grill-me/SKILL.md): the interview, stateless, for when there's no repo to leave a trail in.
- [handoff](./handoff/SKILL.md): write a portable markdown file to seed a session elsewhere.
- [to-questionnaire](./to-questionnaire/SKILL.md): when the gap is in someone else's head, write them a questionnaire.
- [teach](./teach/SKILL.md): learn a topic over multiple sessions in a stateful workspace.
- [wait-what](./wait-what/SKILL.md): a mid-conversation corrective when a message didn't land.

## Model-invoked

- [delivery-dashboard](./delivery-dashboard/SKILL.md): keep one dark status page current after every closed ticket: what needs your input, the latest outcome, five recent entries, a searchable history and a Plan tab of every ticket.
- [grilling](./grilling/SKILL.md): the interview primitive (rounds, frontier; facts are the agent's, decisions are yours).
- [line-craft](./line-craft/SKILL.md): fiction prose and dialogue as acts and errands, checked against a self-testing shape catalog.
- [writing-for-agents](./writing-for-agents/SKILL.md): the reference for writing documents agents consume.
