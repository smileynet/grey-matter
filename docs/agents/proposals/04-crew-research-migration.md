## Global AGENTS.md (draft, 962 B + shim)

```
- Done means evidenced: after a change, run the project's build/test/lint, read the output (not just the exit code), and cite the command and result. Never claim done from a stale run or "should pass".
- Before claiming done, check `git diff`: anything outside the task is a scope violation, so revert or split it. Scale verification depth to reversibility and blast radius, never to diff size.
- Minimal code: no checks the type system already guarantees, no catch-log-rethrow, no comments that restate the code (comments say why), no entry/exit logging, no single-use wrappers or factories.
- Keep defensive validation at trust boundaries (user input, API responses, deserialized data, public library APIs).
- Observed beats documented: running code, real output, and actual bytes outrank specs, docs, and commentary. When they disagree, trust the observation, flag the gap, and say what you verified vs inferred. Absence from a listing or doc is not absence.
- Repos with `.memory/` predate grey-matter: read `.memory/CONTEXT.md` as the glossary and `.memory/adr/` as the decision records until `adopt-project` migrates them.
```

Install to `~/.kiro/steering/AGENTS.md`, `~/.codex/AGENTS.md` (replacing the generated file),
`~/.claude/CLAUDE.md`, and `~/.config/opencode/AGENTS.md`. Track installs in a manifest, the
same way skills are, and never clobber a foreign file.

## Cutover sequence

0. Snapshot `~/.kiro/skills`, `~/.kiro/steering`, `~/.agents/skills`, and `~/.codex/AGENTS.md` into `.scratch/backup/`.
1. Build in grey-matter: the global AGENTS.md + its installer, the fold tickets, and a manifest-scoped crew-research uninstall script.
2. **Pilot:** `adopt-project` on decksmith.
3. Uninstall crew-research (manifest-scoped, dry-run first), decommission recall, install grey-matter skills + the global AGENTS.md.
4. Verify in fresh kiro-cli and codex sessions: the non-crew skills are intact, AGENTS.md is injected, and the shim works in one `.memory/` repo.
5. Freeze crew-research deploys (its init would undo the cutover). Keep the repo as prior art.
6. Run `adopt-project` per repo over time. Remove the shim when no `.memory/` repos remain.

Rollback for steps 3–4: restore the snapshot (or `mise run init -- --global --tier full` from crew-research).
