## Findings and limits

- No unsupported claims or source-snippet mismatches found in the revised note. Its quotations remain below 25 words per source.
- The stable schema version is reported from the TypeScript SDK release history, whose release entries explicitly identify the schema revisions. A future reader should re-check that moving history before relying on the “current” label; the note dates its access and marks this as point-in-time evidence.
- ACP normative docs establish protocol semantics, not conformance by every client or agent. The note consistently labels runtime claims by tested adapter/build and leaves untested peer behavior open.
- Scope did not include the linked workstream source reports' every unrelated claim or private raw captures. No tests/gates were run for this audit-only Markdown companion; `git diff --check` is reported separately at the audit commit.
