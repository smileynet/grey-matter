case descriptions. It is not a replay of the historical sessions, a live-agent prompt

| Case | Existing guidance at base | Added guidance | Assessment |

| #179 missed-wake retrospective | Retro asks for a fresh-context read and broad candidate review, but lacks a loop-specific instruction to separate new evidence from repeated preparation. | Reassess progress and the exact trigger; existing guidance already separates running-agent messaging from idle wake. This review supports the amendment only. It does not establish live skill behavior or
close any broader original ticket criterion not covered by the accepted amendment.
