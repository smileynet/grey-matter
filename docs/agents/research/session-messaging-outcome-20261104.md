# Shared session messaging: bounded outcome

The shared message/session interface, durable handoff lifecycle and owned-worker
adapters are implemented. Native evidence qualifies bounded Windows Codex desktop,
Claude text-worker and Kiro V2 ACP exchanges. This does not provide arbitrary
attachment to user conversations or a universal cross-harness transport.

## Artifact disposition and remaining limits

Tracked implementation, reports, indices and accepted dashboard captures are
promoted as durable project evidence. Parent-owned private qualification records,
failed cases, primary-source snapshots and review helpers are **kept** to reproduce
this acceptance and preserve ambiguous outcomes. Their next disposition event is
an owner-created durable evidence archive plus migration/removal of the private
index references; this requires no new model run. This explicitly extends the
earlier through-final-audit retention scope.

Successful Site package archives are recycled after terminal publication; each
publication provenance record carries the exact archive digest and disposition.
Unrelated files, other sessions' work and private unpublished #171 ancestry remain
untouched. No failed input or historical receipt was rewritten into a success.

Native API-serving model identity, billing/credit entitlement, exact-once delivery,
cross-platform native parity, foreign attachment and reconnect remain unproved.
One older Claude case lacked a launch baseline; its historical descendant
settlement remains unproved despite a later empty current parent-PID graph.
Unsupported/ambiguous routes use explicit manual reporting without blind retry,
provider fallback, new grants or a replacement coordinator.
